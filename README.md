# Time's End

A 1930s rubber-hose rhythm platformer for the browser. The bosses **sing**, and their songs tell you what's about to hit you.

**Tick**, a pocket watch with a metronome pendulum, must escape **Old Smokestack**, a boastful singing locomotive, in *"Full Steam Ahead"*.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static build in dist/
```

The design document, the JSON configuration reference and the roadmap are in [MAIN.md](MAIN.md).

Built with Phaser 3 + TypeScript + Vite. Every visual and sound is generated in code: no external art or audio assets yet.
